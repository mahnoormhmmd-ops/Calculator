🧮 Calculator

This calculator is a simple web application based on HTML, CSS  and Java script.It performs basic arithmetic operations like addition, subtraction, division, multiplication, percentages and decimals.

Demo Link: https://calculator-ashen-xi.vercel.app/

It uses HTML5 for its structure, CSS3 for its dark-themed design, and JavaES6 for functionality, like clicking buttons and them appearing on the interface, performing mathematical operations, then displaying the output on the interface and managing the functions of AC, DEL and =.

I practiced DOM manipulation, event handling, conditional statements, and updating webpage content efficiently through this project. It also strengthened my understanding of JavaScript logic and responsive UI design.

Future improvements include keyboard support, calculation history, a safer expression parser, and a light/dark mode toggle.
